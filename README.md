# Ask My Docs

Build an app that answers questions from your own documents, and shows where each answer came
from. This kind of app is called **RAG**, retrieval-augmented generation.

This is the starter project for the JrCodex project **Build a RAG app**. Follow the chapters
there; this folder holds what you need to begin.

## What's here

- `data/`: the staff handbook of Brightpath Studio, a made-up company. Your app will answer
  questions about it.
- `.gitignore`: files Git should never save, including your secret API key.

There is no code yet. You'll write all of it, one chapter at a time.

## Stuck, or want to compare?

Each chapter's finished code is saved under a tag: `ch02`, `ch03`, and so on.

- Compare your code with the end of chapter 4: `git diff ch04`
- See it on GitHub: switch the branch menu to the tag `ch04`
